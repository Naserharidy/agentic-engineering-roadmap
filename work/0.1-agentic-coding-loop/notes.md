# 0.1 - The Agentic Coding Loop

## Project
Agentic Loop Demo

## Objective
Learn how to use an AI coding agent
while maintaining control over the code.

## 1. Inspect
I inspected the project structure before
allowing the agent to make changes.

## 2. Plan
The agent proposed a step-by-step plan
and listed the required files.

## 3. Approve
I reviewed and approved the plan
before implementation.

## 4. Act
The agent implemented the webpage
using HTML, CSS, and JavaScript.

## 5. Verify
I tested the webpage in the browser.

### Verification Results
- [x] Page loads correctly
- [x] Button works
- [x] Desktop layout works
- [x] Mobile layout works
- [x] No obvious console errors

## 6. Iterate
I reviewed the results and requested
specific fixes when necessary.

## Lessons Learned
- Inspect the project before coding.
- Plan before implementation.
- Approve changes before execution.
- Review the generated code.
- Test the final result.
- Keep changes within the requested scope.

## Summary
The agentic coding loop helped me use
AI coding tools in a controlled way.
